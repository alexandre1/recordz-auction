Les choix derrière le code

Chic Overdose repose sur une pile Java moderne, structurée pour rester lisible, sûre et rapide à mesure que le projet grandit.

Une pile technologique à jour

Java 21 et Spring Boot 3.4 permettent de profiter des dernières évolutions du langage, comme les threads virtuels et le pattern matching avancé.

Avec Vaadin 25, l’interface web s’écrit entièrement en Java, sans framework JavaScript lourd comme React ou Angular à maintenir à côté.

Une architecture en couches

Le projet est un multi-module Maven qui sépare la logique métier (recordz-core) de la partie web (recordz-web).

Les répertoires suivent le même découpage : config, security, model/domain, repository, service et ui. Le code reste facile à maintenir et à faire évoluer.

Des données maîtrisées

jOOQ (3.19) place le SQL au premier plan : contrôle total, précision et performance des requêtes, ce qui compte pour une application d’enchères.

Les tables de référence, comme les cantons suisses et les catégories, sont mises en cache avec @Cacheable pour éviter des accès inutiles à MySQL 9.

Flyway versionne le schéma de la base et fiabilise chaque mise en production.

Une authentification moderne

Spring Security et OAuth2 permettent de se connecter avec Google (Google Sign-In). Les profils utilisateurs sont synchronisés automatiquement par CustomOAuth2UserService, sans mot de passe classique à gérer.

Un projet simple à reprendre

Un fichier docker-compose.yml orchestre les services, MySQL en tête : un nouveau développeur démarre le projet en quelques minutes.

Le README détaille le schéma de données (marché suisse, enchères, cantons) et propose un guide de démarrage pas à pas.
